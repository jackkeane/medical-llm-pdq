How a finetuned LLM gets compressed — shown with a real run

This walkthrough explains model compression using an actual pipeline run: pruning (delete weights), distillation (repair the damage), and quantization (shrink what's left), applied in that order to a finetuned medical 7B model on a single consumer GPU. The starting checkpoint is the one trained in the sibling walkthrough Finetuning, visualized. Every chart on these pages is drawn from the run's real report files — including the stage where accuracy fell off a cliff.

The pipeline at a glance

Compression is a three-move sequence, and the order matters: pruning creates damage, distillation repairs it, quantization compresses the repaired result. Rounded tinted boxes are checkpoints (model files you can load); plain boxes are processing steps. After every step the model retakes the same 100-question exam, so nothing is claimed without a measurement.

The run in one picture

Accuracy on the same held-out 100-question medical exam, measured after every step. Pruning alone cost 13 points by the final stage; distillation won them all back and then some; quantization to 4-bit cost nothing measurable. The dip and the recovery are the whole story of this walkthrough.

Where the numbers come from

This is a real project, not a mock-up. Four runnable scripts produced machine-readable reports, and each chapter cites its sources:

  • reports/iterative_pruning_metrics.json — accuracy and sparsity after each pruning stage
  • reports/iterative_distillation_metrics.json — before/after accuracy per distilled stage
  • reports/quantization_step_metrics.json — fp16 / INT8 / NF4 accuracy and memory footprint
  • reports/awq_vs_nf4_comparison.md — the later AWQ-vs-NF4 head-to-head
  • reports/vllm_serving_metrics.json — serving throughput, memory footprint, and the exam re-run over the API (Chapter 6)
  • run_iterative_pruning.py, run_iterative_distillation.py, run_quantization_step.py, run_awq_quantization_step.py, serve_vllm.sh, run_vllm_serving_benchmark.py — the code itself
